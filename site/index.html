RECOMMENDED · LIVE TELEMETRY

Set up on Windows

For a Windows PC running the Windows x64 version of ATS.

BEFORE YOU START

  • Windows PC with ATS installed through Steam
  • Node.js 20 or newer and Git
  • Your phone and PC on the same trusted Wi-Fi network

INSTALL THE BRIDGE + PLUGIN

In PowerShell, download the project and run the bridge setup:

git clone https://github.com/LeviM-0323/ATS-Companion.git
cd ATS-Companion\bridge
npm ci
npm run setup:plugin
npm start

The plugin setup detects Steam installs or asks you to choose the ATS folder. Restart ATS after installation.

Install the Windows plugin manually

Download ATSCompanionTelemetry.dll from the GitHub Releases page. Copy it to <ATS folder>\bin\win_x64\plugins\ATSCompanionTelemetry.dll, create the plugins folder if needed, then restart ATS.

EXPERIMENTAL · READ THE LIMITS

Linux and Proton

The bridge can be installed on Linux, but the live game-to-phone path has not been verified end to end.

LINUX BRIDGE

Requires Node.js 20 or newer and npm. Building the native plugin also requires g++, curl, sha256sum, and unzip.

git clone https://github.com/LeviM-0323/ATS-Companion.git
cd ATS-Companion
./bridge/linux-install.sh --game-dir "/path/to/American Truck Simulator"

For a native x86_64 Linux ATS installation, the installer builds and installs the Linux plugin. Start the bridge from the printed install path. Pairing and the API are available, but live telemetry remains experimental and not verified.

WHAT ISN'T VERIFIED

  • A fresh live snapshot from native Linux ATS
  • Windows ATS running through Proton with this bridge

Proton runs the Windows game build; the Linux .so plugin is for native Linux ATS only. Do not rely on either Linux route for live telemetry yet.

BRIDGE TAB · ONE-TIME CODE

Pair your phone

Once the bridge is running, connect from the Companion app on the same local network.

01

Open the setup page

On the PC, visit http://localhost:3210/setup. The Windows bridge may open this page for you.

02

Scan or enter the code

In the app's Bridge tab, scan the QR code or enter the bridge address and one-time code.

03

Keep the network private

Allow the bridge through your firewall on private networks only. Keep the phone and PC on the same trusted Wi-Fi.

!

Local network only. The bridge uses port 3210 by default. Do not forward the bridge port or expose it to the public internet.

QUICK CHECKS

Something not working?

The app says “Waiting for telemetry”

On Windows, confirm ATS is running, the plugin is in the correct bin\win_x64\plugins folder, and ATS was restarted after installation. Keep the bridge running and check its console for errors. On Linux, live telemetry has not been verified and may remain unavailable.

My phone can't pair with the bridge

Check that both devices are on the same trusted Wi-Fi, refresh the one-time QR/code, and allow the bridge through your PC firewall for private networks. The bridge address shown in the setup page must be reachable from the phone.

The plugin wasn't installed

Make sure the selected folder contains ATS x64 binaries. For manual setup, use the matching Windows DLL from Releases. Close ATS before replacing a plugin, then restart it.
